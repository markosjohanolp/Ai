---

## 📋 المتطلبات

- حساب GitHub
- حساب Vercel (مجاني — يمكن التسجيل بحساب GitHub)
- بوت تيليجرام (`@termoxrunbot`)
- API شغال على Serv00 (مثبت ومشغّل)

---

## 🚀 النشر على Vercel

### الطريقة 1: عبر GitHub (الأنسب)

1. **أنشئ repo جديد على GitHub** باسم `miniapp`
2. **ارفع الملفات الخمسة:**
   - `index.html`
   - `style.css`
   - `app.js`
   - `vercel.json`
   - `README.md`

3. **روح لـ [vercel.com](https://vercel.com)**
4. **سجّل دخول بحساب GitHub**
5. **اضغط `Add New Project`**
6. **اختر الـ repo `miniapp`**
7. **اضغط `Deploy`**
